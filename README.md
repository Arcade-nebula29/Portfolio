#  NKS Personal Portfolio Website

Welcome to the official repository for my personal portfolio website, showcasing my work at the interdisciplinary intersection of **Applied Physics, Artificial Intelligence, and Computer Vision**.

---

##  Live Demo
* **Live Site (Vercel):** [https://nks-portfolio-mu.vercel.app](https://nks-portfolio-mu.vercel.app)
* **GitHub Repository:** [https://github.com/Arcade-nebula29/Portfolio](https://github.com/Arcade-nebula29/Portfolio)

---

## Key Features

* **Interactive Motion Canvas:** Custom HTML5 Canvas background particle system with touch and hover responsiveness.
* **Modern Claymorphism UI:** Aesthetic glass-nav and clay-card components using Tailwind CSS and custom color themes.
* **Embedded Site AI Assistant:** Floating chatbot drawer trained on portfolio details (skills, projects, education) with quick keywords trigger (`CV`, `projects`, `skills`).
* **CV Modal Preview:** Read-only modal preview with a built-in PDF download/print interface.
* **Fully Responsive:** Optimized layout for desktop, tablet, and mobile browsers.

---

## Built With

* **Markup & Styling:** HTML5, CSS3, CSS (via CDN)
* **Interactivity & Canvas:** Vanilla JavaScript (ES6+), HTML5 Canvas API
* **Icons:** Lucide Icons
* **Deployment & Hosting:** Vercel, GitHub Pages
